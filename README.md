
# Internet Speed Test

Простой консольный инструмент на Python для измерения скорости загрузки
с помощью последовательных HTTP-запросов.

## Возможности

- Принимает URL в качестве аргумента командной строки.
- Выполняет 10 последовательных HTTP-запросов.
- Измеряет время каждого запроса.
- Вычисляет среднее время ответа.
- Измеряет общий объём загруженных данных.
- Вычисляет среднюю скорость загрузки в Мбит/с.

## Требования

- Python 3.8+
- Внешние зависимости не требуются.

## Использование

Клонируйте репозиторий:

```bash
git clone https://github.com/TysboProg/internet-speed-test.git
cd internet-speed-test
```

Запустите скрипт:

```bash
python main.py https://httpbin.org/image/jpeg
```

## Пример вывода

```text
Request 1/10: 0.532 секунд, 1024.00 Килобайт
Request 2/10: 0.724 секунд, 34.75 Килобайт
...

---Результат---
Средняя скорость ответа: 0.625
Скачано мегабайт: 0.339
Скорость интернета: 0.456
```

## Единицы измерения

- Время ответа: секунды (sec)
- Загруженные данные: мегабайты (MB)
- Скорость загрузки: мегабиты в секунду (Mbps)

Скорость загрузки рассчитывается как общее количество
загруженных бит, делённое на общее время выполнения.
